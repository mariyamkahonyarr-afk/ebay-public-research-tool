VeRO / brand warning: if the product is branded, a supplier listing it does not prove you may sell it. Check the brand's VeRO profile and authorisation, use original photos/copy, and never use a brand name for a generic item unless it genuinely is that brand.

Winner Scorer — 18-point checklist (research report §1.14)

Score each row 0 = fail/unknown, 1 = acceptable, 2 = strong. Unknown = 0, never assume good. Tick HARD FAIL if that row is a hard fail (branded/VeRO, negative margin, no verifiable supplier, 15+ day untracked delivery, fragile/liquid) — any hard fail = Kill, whatever the total. Decision: 30–36 Scale, 22–29 Keep & improve, under 22 Kill. This is a researcher checklist, not eBay data.

What this tool shows — and what it does not

Live listings only, from eBay Browse API in the same search. The All markets total is the sum across the 8 markets, not a count of unique products. Chances of Success and Winning / Neutral / Losing are TOOL scores from the rows in this search (sales est. > 0 = 40 points; feedback ≥ 1000 = 25 / ≥ 100 = 15 / ≥ 10 = 5; price ≤ search average = 20 / ≤ average × 1.2 = 10; condition containing New / Ungraded / Factory Sealed = 15; capped at 100; Winning ≥ 70, Neutral 40–69, Losing < 40). They are not eBay data and not a guarantee.

Honest limits, read before trusting any tab: (1) No global sold history, no ZIK sold database, no 5M-product Turbo database — Turbo / Top / Market tabs work from your last search only. (2) No live Amazon / Walmart / AliExpress / Alibaba / CJ prices — Supplier Finder gives search links only, plus a calculation from a price you type in. (3) No server-side 24/7 Autopilot — saved scans run only when you press Run in this browser. (4) No connected-store analytics and no Chrome extension — those need store OAuth and a browser extension, which a website cannot provide. (5) Sales (est.) comes only from single-market searches, via eBay item details, and is labelled est. because eBay itself calls it an estimate. A missing field is always shown as Not specified, never invented.

Two honest options for real sold history remain: (1) collect live data daily and build sold history over time, or (2) keep running as live listings only.

Help — How to use HSQ ECOMMERCE

Workflow: 1) Product Research search. 2) Explorer filter. 3) Winner Scorer (auto-fill, then manual). 4) Profit Calculator. 5) Supplier Finder (search links + typed price). 6) Watchlist save.

Badges: FACT = eBay field as returned. ESTIMATE = eBay estimated sold quantity, competitor revenue, keyword demand. CALCULATED = tool score, profit, margin, ROI — formula shown, never eBay data.

eBay limits: No sold history, no global trends, no live supplier prices in this version. ALL-market searches have no per-item sales (est.) to avoid timeouts. Single-market searches do.

Profit: Fee = fee% × (selling price + buyer-paid sales tax) + per-order $0.30 (≤$10) / $0.40 (>$10). Profit = selling price − product cost − shipping − fee − promoted − returns reserve. Sales tax itself is not profit.

Supplier guidance: Search links are not price matches. Type the price you verified, check VeRO/brand authorisation, order a sample, and confirm blind packaging and returns before scaling.
