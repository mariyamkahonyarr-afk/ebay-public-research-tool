Competitor Research

Type a seller name in the main search? No — in this public version, click a seller name in the Live Listings table and search that seller's other listings by using the same keyword search, then filter by seller in your head. A full seller-page (revenue, sold, active, successful %, sell-through) needs seller-level sold history, which Browse API does not provide.
