What this tool shows — and what it does not

Live listings only, from eBay Browse API in the same search. The All markets total is the sum across the 8 markets in the market map, not a count of unique products. Sales (est.) is eBay's estimated sold quantity from the item-detail call, for single-market searches only. A failed sold call is never replaced with an invented number or a search total.

Owner note: EBAY_APP_ID and EBAY_CERT_ID stay only in Vercel Environment Variables. Never put them in this page or in a public Git repo.
